# skills

Open-source AI agent skills. By [Abas Turabli](https://fearchitect.com).

| Skill | Description | Install |
|---|---|---|
| fe-architect | Frontend architecture decision advisor across 12 domains | `npx skills add DevAbas/skills -s fe-architect` |
| react-audit | React/Next.js structural fragility auditor | `npx skills add DevAbas/skills -s react-audit` |

## Claude Code plugins

Add the marketplace once, then install a plugin:

```bash
claude plugin marketplace add DevAbas/skills
```

| Plugin | Description | Install |
|---|---|---|
| [design-tokens](plugins/design-tokens) | Set up, audit, fix and gate a web project's design-token architecture (W3C DTCG). Ready-made gates for Tailwind CSS v4 + Terrazzo; core rules for other web stacks. See its [stack and dependencies](plugins/design-tokens#stack-and-dependencies) | `claude plugin install design-tokens@fearchitect` |
